# FairJobs – Simple Transparent Job Board

A beginner-friendly job listing app built with **only HTML, CSS, JavaScript and PHP**.  
No frameworks. Easy to understand and explain.

## Why this app exists
Most job boards have ghost jobs, hidden salaries, broken filters and applications that disappear.  
FairJobs forces salary transparency, shows clear remote status, keeps dates fresh, gives instant apply confirmation, and has filters that actually work.

## Features
- List of jobs with salary, remote badge, location and date
- Live search + filters (keyword, location, min salary, remote)
- Job detail page
- Easy apply form with instant success message
- Post a new job form (demo)
- Fully responsive

## How to run locally

1. Make sure PHP is installed (`php -v`)
2. Open a terminal inside the `fairjobs` folder
3. Run:
